# МастерОк — сайт строительной мастерской

Статический адаптивный сайт-портфолио для строительной мастерской «МастерОк».

## Как посмотреть

Откройте `index.html` в браузере. Сервер и backend для демонстрации не нужны.

## Структура проекта

- `index.html` — разметка страницы;
- `css/styles.css` — стили, адаптивность и анимации;
- `js/main.js` — фильтры портфолио, просмотр проектов и интерактивность;
- `assets/projects/` — локальные фотографии проектов.

Форма заявки работает как демонстрация и не отправляет данные на сервер.
