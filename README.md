# МастерОк — сайт строительной мастерской

Статический адаптивный сайт-портфолио для строительной мастерской «МастерОк».

## Как посмотреть

Откройте `index.html` в браузере. Сервер и backend для демонстрации не нужны.

## Структура проекта

- `index.html` — разметка страницы;
- `css/styles.css` — стили, адаптивность и анимации;
- `js/main.js` — фильтры портфолио, просмотр проектов и интерактивность;
- `assets/projects/` — локальные фотографии проектов.

Форма заявки работает как демонстрация и не отправляет данные на сервер.

## Используемые библиотеки

- **Bootstrap 5.3.8** — утилиты и оформление полей формы. Файл хранится локально в `assets/vendor/`, поэтому CDN при запуске не нужен.
- **GSAP 3.13.0** — вступительная анимация заголовка и декоративных элементов. Если библиотека недоступна или включено уменьшение движения, остаются CSS-анимации и обычная версия страницы.

В исходниках оставлены разговорные комментарии: они объясняют, зачем нужен блок, и помогают следующему человеку не гадать, куда пропал нужный пиксель.
