# МастерОк — сайт строительной мастерской

Статический адаптивный сайт-портфолио для строительной мастерской «МастерОк».

## Как посмотреть

Откройте `index.html` в VS Code через расширение **Live Server** (или любой статический сервер). Backend для демонстрации не нужен.

## Структура проекта

- `index.html` — разметка страницы;
- `css/styles.css` — стили, адаптивность;
- `js/main.js` — фильтры портфолио, просмотр проектов, интерактивность и все анимации;
- `assets/projects/` — локальные фотографии проектов;
- `assets/vendor/` — локальные копии Bootstrap CSS и GSAP.

## Используемые библиотеки

- **Bootstrap 5.3.8** — CSS лежит локально в `assets/vendor/bootstrap.min.css`. JS-бандл (`bootstrap.bundle.min.js`) подключается через CDN: включает валидацию форм, тосты и прочие компоненты, управляемые через `data-bs-*`.
- **GSAP 3.13.0** — локально в `assets/vendor/gsap.min.js`. Все появления блоков, счётчики, «магнитные» ссылки, наклон карточек, параллакс обложки и полоса прокрутки работают на GSAP.
- **ScrollTrigger** — плагин GSAP, подключается через CDN. Если он не загрузится, блоки появятся через `IntersectionObserver`, а полоса прокрутки будет крутиться старым RAF-обработчиком.

## Что переписано на GSAP

- Появление `.reveal`-блоков (было: `IntersectionObserver` + CSS-переход → стало: `ScrollTrigger` + `gsap.to`);
- Счётчики цифр (было: ручной `requestAnimationFrame` → стало: `gsap.to` по объекту-состоянию);
- «Магнитные» ссылки (было: инлайн-`transform` вручную → стало: `gsap.quickTo` по `x`/`y`/`scale`);
- Наклон карточек (было: CSS-переменные и CSS-transition → стало: `gsap.quickTo` по `rotationX`/`rotationY`, CSS-переменные остались для радиального блика);
- Полоса прокрутки (было: `requestAnimationFrame` на `scroll` → стало: `ScrollTrigger` + `quickSetter` по `scaleX`);
- Параллакс hero-обложки (было: инлайн `backgroundPositionY` → стало: `ScrollTrigger` со `scrub: true`);
- Вспышка цены в калькуляторе (было: CSS-класс `.updated` → стало: `gsap.fromTo` с `clearProps`);
- Появление диалога калькулятора (было: `.visible` через CSS → стало: `gsap.fromTo` со `stagger`);
- Бегущая строка направлений (было: CSS-keyframes → стало: `gsap.to` с `repeat: -1` по `xPercent`).

Фолбэки на `IntersectionObserver` и CSS остались на случай, если CDN недоступен или пользователь включил `prefers-reduced-motion`. В исходниках оставлены разговорные комментарии — они объясняют, зачем нужен блок, и помогают следующему человеку не гадать, куда пропал нужный пиксель.
